# AstrBot Plugins Archive

这是 `memoriass` 的公开 AstrBot 插件旧代码参考归档仓库。

## 定位

- 本仓库是参考归档，不是正在使用的 AstrBot 插件市场源。
- 除 `planabot` 外，相关旧 AstrBot 插件项目均按仓库和分支保存。
- 每个项目同时保留分支快照和 Git bundle，便于查阅历史和恢复完整 Git 对象。
- 新功能和持续维护不在本仓库进行；请勿将其作为生产插件源使用。

## 内容

归档项目、来源、分支、提交和快照路径见 `ARCHIVE_MANIFEST.json`。归档包含公开旧插件以及原先的私有 Plana 相关 AstrBot 插件代码；这些内容现随归档仓库公开。

## 许可与来源

各项目目录中的许可证、版权声明和原始文档按归档时保留。使用或再发布代码前，请阅读对应项目的许可证和第三方声明。

## 维护规则

归档更新应使用源仓库的明确提交重新生成，并同步更新 `ARCHIVE_MANIFEST.json`。不要提交运行数据、缓存、凭据或本地构建产物。
