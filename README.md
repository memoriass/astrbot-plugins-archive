# AstrBot Plugins Archive

这是 `memoriass` 的 AstrBot 插件参考归档仓库，用于集中保存已停止独立维护、仍需查阅或迁移的插件快照。

## 定位

- 本仓库是只读参考归档，不是 AstrBot 插件市场源。
- 归档内容来自独立插件仓库的干净提交，保留原目录结构和许可证文件。
- 新功能和持续维护不在本仓库进行；请以各插件原仓库的状态为准。
- 本仓库不包含 Planabot、Plana Gallery 或 Plana Webhook 相关内容。

## 许可与来源

每个插件目录中的许可证、版权声明和原始 README 均按归档时的源仓库保留。使用或再发布某个插件前，请先阅读对应目录中的许可证和说明。

## 维护规则

归档更新应使用源仓库的明确提交重新生成，并同步更新 `ARCHIVE_MANIFEST.json`。不要把运行数据、缓存、凭据或本地构建产物提交到本仓库。
