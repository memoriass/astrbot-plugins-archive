Plana Core 架构预览

当前图表基于项目审计结果整理，重点呈现插件接手开发所需的模型架构、框架内秘书中枢边界、多模型顾问层、能力裁剪方向，以及受控 workflow 内核。

1. 整体模型架构

入口层保持薄入口，业务能力集中到运行时和服务模块；长期状态进入 SQLite 数据层；Web 与 Bridge 均通过受控服务边界访问核心。

2. 能力地图与收敛状态

当前优化重点不是无限扩能力，而是在 AstrBot 框架内保留秘书中枢，关闭高风险外扩能力，并把自主 workflow 缩到可注册、可校验、可审计的内核。

flowchart LR
  start["当前接手目标
稳定记忆核心，收敛外扩能力"] --> keep

  subgraph keep["A. 核心保留能力"]
    k1["记忆建模
Identity / Session / Persona / Scope"]
    k2["记忆存储
Episodic / Semantic / Tool / Relation / Concept"]
    k3["召回与注入
RecallEngine + PromptBuilder"]
    k4["记忆激活
MemoryActivator"]
    k5["任务与规则
TaskQueue + RulePlanner"]
    k6["安全与审计
SafetyGate + PendingTask + AuditLog"]
    k7["管理面板
Embedded Dashboard + Admin API"]
    k8["受控协作
Bridge Gateway + plana_requests"]
  end

  keep --> review
  subgraph review["B. 保留但必须闭环"]
    r1["memory_embeddings
需明确生成、更新、检索策略"]
    r2["person_info
需定义信息来源与确认边界"]
    r3["PAD 情绪持久化
需验证真实产品价值"]
    r4["反馈处理器
需接入可审计的改进闭环"]
  end

  keep --> cut
  subgraph cut["C. 默认关闭或裁剪"]
    c1["TTS 默认关闭

    c2["Active Send 默认关闭
注册必须配置 token"]
    c3["Standalone Web 默认本地监听
非回环且无密码拒绝启动"]
    c4["自由 Workflow 裁定裁剪
改为 registry + compiler"]
  end

  review --> next
  cut --> next
  subgraph next["D. 后续最小演进"]
    n1["Secretary Workflow Kernel
框架内秘书中枢"]
    n2["多模型顾问可辅助规划与审计

3. 多模型协作与 Workflow 决策

多模型交互保留为秘书中枢的顾问层，可调用高编程能力模型做计划与审计，但执行权留在本地 compiler、SafetyGate 与服务层。

flowchart TD
  ext["外部模型 / 主 LLM / 管理端"] --> router["Secretary Router"]
  router --> advisor["Advisor Layer
planner / coding / critic / memory"]
  advisor --> intent["intent / audit report / workflow draft"]
  intent --> registry["Capability Registry
只允许已注册 step"]
  registry --> compile{"Compiler 校验通过?"}
  compile -->|否| reject["拒绝
unknown_step / invalid_schema / over_budget"]
  compile -->|是| validate["本地校验
identity / session / scope / permission"]

  validate --> ro{"是否只读?"}
  ro -->|是| direct["直接执行并返回
search / list / diagnostics / status"]
  ro -->|否| sideEffect{"是否写入、删除、批量变更
或改变账号/外部状态?"}

  sideEffect -->|是| pending["确认边界
PendingTask / Admin UI / 用户确认"]
  pending --> audit["审计记录
actor / request / params / result"]
  audit --> service["执行本地服务层
禁止外部模型直接落库或执行副作用"]

  sideEffect -->|否| guarded["安全门执行
SafetyGate + service API"]

  direct --> result["标准化结果返回"]
  guarded --> result
  service --> result
  result --> ext

  subgraph current["当前保留策略"]
    c1["框架内秘书中枢"]
    c2["多模型可产出计划、审计、workflow draft"]
    c3["step 必须来自本地 registry"]
    c4["副作用必须经过确认与审计"]
  end

  subgraph rejectPlan["当前不建议引入"]
    x1["自然语言直接执行 workflow"]
    x2["顾问模型直接编排副作用链"]
    x3["绕过 PendingTask / AuditLog 的写操作"]
    x4["无 schema、无权限、无审计的动态工具调用"]
  end

  subgraph future["Secretary Workflow Kernel"]
    f1["注册稳定能力 step"]
    f2["固定输入 schema"]
    f3["明确权限与确认策略"]
    f4["全链路审计"]
    f5["候选：memory.search / task.propose / memory.propose_write"]
  end

  intent -.-> current
  pending -.-> rejectPlan
  audit -.-> future
